プライバシーポリシー

最終更新日：2026年11月3日

1. 本ポリシーの対象

本ポリシーは、「アニメ特撮反応局 動画投稿ツール」（以下「本ツール」）における 情報の取り扱いについて定めるものです。

2. 本ツールの性質

本ツールは一般に提供されるサービスではなく、チャンネル所有者本人が、 自身のYouTubeチャンネルを操作するためだけに利用する個人用ツールです。 所有者以外の利用者は存在せず、第三者が登録・利用することはできません。

3. 取得する情報

本ツールは、Googleアカウントによる認可（OAuth 2.0）を通じて、以下の権限を取得します。

権限（スコープ）用途
https://www.googleapis.com/auth/youtube.upload 動画をYouTubeへアップロードするため
https://www.googleapis.com/auth/youtube.force-ssl アップロードした動画のタイトル・説明文・公開日時・サムネイルを設定し、処理状況を確認するため
https://www.googleapis.com/auth/yt-analytics.readonly 投稿する時間帯を調整する目的で、所有者自身のチャンネルの再生数などの統計を参照するため

本ツールは、氏名・住所・電話番号・支払い情報といった個人情報を取得しません。 また、視聴者個人を特定する情報を収集することもありません。

4. 情報の保存

認可によって得られるリフレッシュトークンは、所有者のPC上のファイル （.youtube-token.json）にのみ保存されます。 本ツールは独自のサーバーを持たず、取得した情報を外部へ送信・保管することはありません。

5. 第三者への提供

取得した情報を、第三者へ提供・販売・共有することはありません。 広告配信や分析のための外部サービスにも連携していません。

6. 情報の利用範囲

取得した権限は、所有者自身のYouTubeチャンネルに対する操作にのみ使用します。 他者のチャンネルやアカウントに対して使用することはありません。

7. アクセス権の取り消しと削除

所有者は、以下のいずれかの方法で、いつでも本ツールのアクセス権を取り消せます。

  • Googleアカウントのセキュリティ設定 （myaccount.google.com/permissions） から、本ツールのアクセス権を削除する
  • 所有者のPC上にある .youtube-token.json を削除する

取り消しを行うと、本ツールはYouTubeへアクセスできなくなります。

8. YouTube API サービスの利用について

本ツールは YouTube API Services を利用しています。本ツールの利用にあたっては、 YouTube 利用規約および Google プライバシーポリシーが適用されます。

9. 本ポリシーの変更

本ポリシーを変更する場合は、本ページ上に変更後の内容と最終更新日を掲載します。
